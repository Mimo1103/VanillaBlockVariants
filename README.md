# Introduction
Vanilla Block Variants adds the block variants that are missing from vanilla
Minecraft, expanding existing block families with new building options and new block
types like Diorite Tiles.

# Content
- Granite Bricks, Walls, Stairs and Slabs
- Terracotta Walls, Stairs and Slabs
- Glazed Terracotta Walls, Stairs and Slabs
- Concrete Walls, Stairs and Slabs
- Wool Walls, Stairs and Slabs
- Netherrack Walls, Stairs and Slabs
- Dripstone Tiles, Walls, Stairs and Slabs
- and much more!
